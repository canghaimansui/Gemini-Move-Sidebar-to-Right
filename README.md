# Gemini_Move_Sidebar_to_Right
因为习惯浏览器标签栏在左边，但是Gemini边栏也在左边，导致正文太靠右。所以找Gemini自己写了个油猴脚本，把默认居左的边栏挪到右边去，确保对话正文主体居中。

利用了阿拉伯语（从右到左）的排版机制实现。
<br><br><br>


### 食用方法
1. 浏览器安装油猴/Tamper Monkey扩展插件：[篡改猴 - Chrome 应用商店](https://chromewebstore.google.com/detail/%E7%AF%A1%E6%94%B9%E7%8C%B4/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=zh-CN)
2. 访问GreasyFork中本脚本的链接：[Gemini侧边栏从左侧移动到右侧](https://greasyfork.org/zh-CN/scripts/601533-gemini%E4%BE%A7%E8%BE%B9%E6%A0%8F%E4%BB%8E%E5%B7%A6%E4%BE%A7%E7%A7%BB%E5%8A%A8%E5%88%B0%E5%8F%B3%E4%BE%A7)
3. 单击安装，安装完毕后刷新Gemini即可。
完毕。
